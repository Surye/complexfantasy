# complexfantasy

Static reports for **The Complex League**, published via GitHub Pages.

- `index.html` — **State of the League**: season home page (standings, weekly
  results grid, power rankings, season honors, and an LLM-written address), updated
  each week
- `weekly_report_YYYY_wkN.html` — individual week reviews
- `season_2025.html` — 2025 full-season report

Generated locally by `weekly_report.py` and `state_of_league.py`, then published
with `publish.sh`. This repo contains generated HTML only.
